# Kondisonair

**Kondisonair**（コンディソネイル）は、私が自分の人工言語を整理・共有するために作ったプラットフォームですが、他のコンラング制作者の役にも立つと思い公開しています。音、音節構造、品詞クラス、文字体系、語彙、活用・屈折表、そしてコンラングで書かれたテキストを設定できます。言語の進化をシミュレートする単語ジェネレーターや音変化ツールなども備えています。

## 機能
- **コンラングの整理**: 次のような詳細を持つ言語を作成・編集できます。
  - 音: 音素表を定義します。
  - 音節構造: 音節を構成します。
  - 品詞クラス: 名詞、動詞などを整理します。
  - 活用・屈折表: 動詞や名詞などのパラダイムと自動活用を作成します。
  - 文字体系: オリジナルのアルファベットや文字を作成します。
  - 語彙: 詳細な意味付きで単語を追加します。
- **共有**: プラットフォーム上で、作成した言語をコミュニティに直接公開できます。
- **単語ジェネレーター**: 音節パターンに基づいて単語を自動生成します。
- **音変化ツール**: 音変化をシミュレートします。
- **コンラングのテキスト**: テキストをアップロードし、インタラクティブな読解練習ができます。
- **世界の構築**: 言語が話されている世界を作成・編集できます。
  - 時間体系: オリジナルの暦を作成します。
  - エンティティ: 世界に登場人物や場所を追加します。
  - パラメーター: エンティティにパラメーターを結び付けて進行を追跡します。
  - 年表: 歴史上の重要な出来事を追加します。
  - 物語: エンティティや出来事に結び付いたテキストを書きます。

## 使用技術
- PHP、MySQL、JavaScript、[Tabler](https://tabler.io)、[jQuery](https://jquery.com) など

**注**: これはComposerやnpmを使わないシンプルなプロジェクトです。依存ライブラリはファイルに含まれています。

**注2**: コードの多くの部分はAIの助けを借りて作成されました。
